# Security Policy

## Supported Versions

The following versions of this project currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

We take the security of this repository and its datasets seriously. If you believe you have found a security vulnerability, data leakage issue, or compliance breach in any transcript record or tool script, please report it responsibly.

### How to Report

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report vulnerabilities by emailing the maintainer team at `security@awesome-tech-talks.org` or through GitHub Private Vulnerability Reporting on this repository.

Please include the following information in your report:
* Type of issue (e.g., secret leakage, unauthorized personally identifiable information, script execution vulnerability)
* Location of the issue (file paths, line numbers, or specific JSON record IDs)
* Step-by-step instructions to reproduce the issue
* Proposed remediation, if known

### Response Process

* You will receive an acknowledgment of your report within 48 hours.
* The maintainers will assess the risk, confirm the vulnerability, and coordinate an appropriate fix.
* Once resolved, a patch will be committed and credited in the release notes unless you prefer to remain anonymous.
